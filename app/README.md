# 📱 Pookie Client (Anti Gravity Game Engine / Android)

This directory hosts the client application for Pookie.

## 🎮 Engine Integration
- **Framework:** Anti Gravity Engine
- **State Machine:** Deterministic client-side state machine with adaptive polling heartbeat.
- **Design Philosophy:** Aesthetic, couple-centric micro-interactions, haptics, and zero-account instant play.

Refer to [`docs/architecture/STATE_MACHINES.md`](../docs/architecture/STATE_MACHINES.md) for state transitions and heartbeat logic.
